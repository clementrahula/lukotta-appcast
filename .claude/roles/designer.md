# designer, in this project

The role itself is shared and lives outside this repository, at `~/.claude/agents/designer.md`.
If you have cloned this project that file will not be there, and nothing here depends
on it: what follows is a description of THIS repository's commands, paths and hazards,
which is useful on its own. Where both exist, this file wins.

**This role cannot run here.** There is no screen: this repository serves two XML feeds that an updater reads. The rendered release notes under `notes/` are HTML shown inside the application's update dialog, and are judged there, in the application, rather than here.
