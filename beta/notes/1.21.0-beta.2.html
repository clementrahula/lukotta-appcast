Version 1.21.0-beta.2

  • Drives formatted NTFS can be written to, not only read. They mount with the in-kernel driver where it is there and fall back to ntfs-3g where it is not, and the fallback is no longer handed mount options it refuses.
  • Opening an NTFS drive read-only works again. It had been passing the mount command two separate option flags, which that command does not accept, so nothing mounted at all.
  • The update dialogs are in the language the rest of the app is in, and where a release has notes in that language, those are the notes shown.
  • Quitting asks once instead of twice, says that it is quitting while it does it, and no longer holds the window still for the last part. Eject and quit together no longer leaves the app on screen doing nothing.
  • Rescan shows that it ran.
